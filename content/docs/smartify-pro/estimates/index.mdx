## Estimate statuses

| Status | Meaning |
|---|---|
| **Draft** | Work in progress — not yet shared with the client |
| **Sent** | Shared with the client via PDF link or WhatsApp |
| **Accepted** | Client has accepted the quote |
| **Rejected** | Client has declined the quote |

You can filter your estimates list by status using the tabs at the top of the Estimates page.
